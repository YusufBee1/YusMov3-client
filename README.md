# myFlix Client

A single-page React app that allows users to browse movies, manage their profile, and add/remove favorites.

## Features

- User login/signup with JWT
- View movie details
- Add/remove favorites
- Filter movies by title
- Update profile or delete account
- Responsive Bootstrap UI

## Technologies

- React
- React Router
- Bootstrap
- JWT Auth
- Hosted on Netlify

## Setup

1. Clone the repo
2. Run `npm install`
3. Add `.env` with `VITE_API_URL=http://your-api-url`
4. Run `npm run dev`
